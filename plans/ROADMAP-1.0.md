# Cove 1.0 Roadmap（2026-09-12 圈定）

尺子：North Star「Mac 上的一流 NAS 媒体中心」= 媒体消费闭环完整 +
分发可信 + 无体验窟窿。缺口均经代码实证（2026-09-12）。

## A. 媒体消费闭环（进 1.0）

1. **音频播放**：分类表无 audio 类型（mp3/flac/aac 全无实证）；复用
   现有 libmpv 桥接播放，UI 壳可后补。工作量中。
2. **外挂字幕**：srt/ass 已分类 text 但挂不上视频；mpv 原生 sub-file
   加载，内嵌轨开关的姊妹项。工作量小-中。
3. **搜索**：全仓无 NSSearchField（实证）；一期=当前 share/vault
   名称过滤（本地 list 过滤零网络成本），远期全盘索引。工作量小。
4. **继续观看**：PlaybackProgressStore 数据已在，无入口；idle/首页
   「最近播放」卡片排。工作量中。

## B. 分发与信任（进 1.0）

5. **DEVELOPMENT_TEAM + 真 bundle id**：BACKLOG「上架前必须」，随
   1.0.0 tag 压哨做。
6. **更新通道**：无 Sparkle（实证）；一期=「检查更新」（gh releases
   API 比对 + 跳转），可升级 Sparkle 2。工作量小-中。

## C. 体验地基（进 1.0）

7. **T1 空态/加载态清扫**：share 网格加载静态文案、空文件夹零提示、
   目录切换无加载态（audit 残余）。工作量小-中。

## 候选（看节奏，可放 1.x）

8. **图片网格墙**：照片库场景的新布局 + 缩略图管线压力，工作量大。

## 明确排除（不进 1.0）

iPad 端（2.0 级）、播放器多窗口、目录模式 decode-ahead（实测慢再做）、
cbr、投屏、多语言。

## 序列

小先行：搜索 → T1 清扫 → 检查更新（三张快卡）→ 体验三连：外挂字幕
→ 继续观看 → 音频播放 → TEAM/bundle id 压哨随 1.0.0 tag。
